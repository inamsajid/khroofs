# K.H. Roofing Contractors - Redesigned Website

A modern, minimalist, high-converting web interface designed for **K.H. Roofing Contractors Ltd** (Manchester & North West).

---

## 🎨 Brand Design System & Color Palette
The redesign adheres to the authentic brand colors of **khroofs.com**:
- **Primary Brand Gold / Amber**: `#FFC917` (High-contrast primary CTAs, highlight borders, badge accents, rating stars)
- **Deep Slate / Obsidian**: `#0B0F17` (Night background for hero, sticky glass navigation, and footer)
- **Rich Charcoal**: `#181E29` / `#242222` (Card backdrops and contrast sections)
- **Porcelain / Clean Minimal Light**: `#FAFAFA` and `#FFFFFF` (Airy readability for content, about, and services)
- **Trust Sky Blue**: `#0284C7` (Secondary accents, flat roofing indicators)

## 🚀 How to Run Locally

You can simply open `index.html` directly in any web browser, or serve it using Python or Node.js:

```bash
# Using Python
python -m http.server 3000

# Using Node.js
npx serve .
```

Open `http://localhost:3000` in your browser.
